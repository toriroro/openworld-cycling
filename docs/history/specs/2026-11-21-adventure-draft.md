# 冒険の乗り方（実際の運動の記録で探索が広がる）概念設計（草案）

2026-11-21 草案。ユーザーの考え（2026-11-21）: Garmin や Apple Watch で計った 1 日の運動の記録をアプリに取り込むと、その距離に応じてゲームの中のライダーが自動で走ってくれる。たとえば 1km 走ったら、ゲームの中では 10km 探索できる。箱庭の要素として足したい。「最初から全部を探索できるオープンワールド」とどちらがよいかは五分五分なので、両方を選べる形で進める。

同日、【要判断】1〜12 をすべて推奨どおりに決定（1 自由と並べる、2 未走行の道を進む時だけ使う、3 距離 × 種目の倍率、4 倍率は 3.2 の【初期値】、5 ファイル → HealthKit → API の順、6 冒険を始めた日の 7 日前から、7 手で打ち込む取り込みは置かない、8 ほかの物と交換できない、9 閉じている間も旅を進める、10 トレーナーでは使わない、11 自由 → 冒険ははじめからでだけ、12 A1 をトレーナーの実機の確認を待たずに進める）。

記号: 【仮定】= 確認なしで置いた前提。【要判断】= 決めてもらいたい点。【初期値】= 動かして調整してよい数値。【未確認】= 実機・実測で確かめていないこと。

前提として読んだもの: [概要仕様](2026-11-13-openworld-cycling-overview.md) 1・2・4.4・5.3・6・9.4・12・13、[モック仕様](2026-11-13-mock.md) 7.2〜7.4、[トレーナー連携の草案](2026-11-20-trainer-draft.md)、`src/sim/ridden.ts`（走った区間を道路ごとに 10m の区切りで持つ）、`src/sim/watch.ts`（眺める乗り方の「未走行の道を優先」）、`src/ui/world-map.ts`（走った道を太く描く）、`tests/fit-decode.ts`。

## 0. 要点

1. **世界を始める時に「自由」と「冒険」を選ぶ（推奨）。** 自由は今のまま、最初から全部を走れる。冒険は、まだ走っていない道を進むのに「冒険の距離」を使う。世界（生成の世界・北海道）ごと、保存ごとに選ぶ。どちらかに決めてしまわない。
2. **使うのは「まだ走っていない道」を進む時だけ（推奨）。** 一度走った道は、何度でも自由に走れる・眺められる。探索して広げた世界は自分の物になる。走った区間は今の `RiddenLog`（10m の区切り）でそのまま数えられる。
3. **冒険の距離は、実際の運動の記録を取り込んで増やす。** 種目ごとの倍率を掛ける。ラン 1km → 10km【初期値】（ユーザーの例）。ウォーキング・自転車・水泳にも倍率を持つ（3.2）。
4. **取り込んだら、ライダーが自分で走り出す。** 眺める乗り方の「未走行の道を優先」で、冒険の距離が無くなるまで走る。アプリを閉じている間も、旅は進んだことにする（A2。戻った時にまとめて進め、その日の旅の記録を見せる）。
5. **最初の取り込み方はファイル（推奨）。** Garmin Connect・Strava などから書き出した FIT・GPX・TCX を、画面で選んで読む。サーバーも外部のサービスの登録も要らず、ウェブ版だけでできる。Apple Watch（ヘルスケア）は iOS アプリ（P4）で HealthKit から読む。Strava・Garmin の API は、サーバーを持つ P3 の後に検討する。
6. **取り込むのは合計だけ。** 種目・日時・距離・時間だけを残し、位置の列（家の場所が分かる）は端末の中でも保存しない。サーバーへも送らない。
7. **トレーナーで走るのは、冒険の距離を使わない（推奨）。** 実際に漕いでいるので、走った分がそのまま探索になる。キーボード・タッチの手動と、眺める乗り方は使う。

## 2. 自由と冒険

| | 自由 | 冒険 |
|---|---|---|
| 走れる所 | 全部 | 走った道は全部。まだ走っていない道は、冒険の距離がある間だけ |
| 地図 | 今のまま（走った道を太く、未走行を細く） | 走った道とその周り 300m【初期値】だけ描く。ほかは地形だけ |
| 眺める乗り方 | 今のまま | 冒険の距離があれば「未走行の道を優先」で広げる。無くなったら、走った道の上だけを走り続ける |
| 手動（キー・タッチ） | 今のまま | 未走行の道で使う。無くなったら、未走行の区間の手前で止まる |
| トレーナー | 今のまま | 使わない（0 章の 7） |
| 喫茶店・名所・スタンプ | 今のまま | 同じ。名所帳の行き先は、着くまでの未走行の道のりが冒険の距離より長いと選べない（距離を表示する） |

- 「はじめから」で選ぶ。続きからの保存に入る。
- 冒険 → 自由へはいつでも変えられる。自由 → 冒険は「はじめから」でだけ【初期値】（自由で走った道が全部「走った道」になってしまうため）。11 章の 2。
- 最初に 20km【初期値】の冒険の距離を持って始める（取り込む前に遊び方が分かるように）。

### 2.1 残りが無い時

- 手動: 未走行の区間に入る 30m 手前から減速し、区間の手前で止まる。「冒険の距離が無い（運動の記録を取り込むと増える）」を出す。U ターン・分岐の選び直しはできる。
- 眺める: 分岐で未走行の道を選ばない。走った道だけで行き止まりになったら折り返す。走った道が全く無い所（ワープした先）では止まる。
- ワープ（世界地図の「ワープ」）は、冒険では走った道の上か、立ち寄った店・名所へだけ【初期値】。

### 2.2 数え方

- `Ride.step` で道のりが進んだ時、今いる 10m の区切りが `RiddenLog` にまだ無ければ、進んだ道のりを冒険の距離から引く。もう有れば引かない。
- 冒険の距離は帳簿で持つ: 増えた記録（取り込んだ記録 1 件ごと）、使った量の合計、残り。画面に「冒険の残り 12.4 km」。

## 3. 取り込み

### 3.1 ファイル

| 形式 | 主な出どころ | 読む値 | 種目 |
|---|---|---|---|
| FIT | Garmin Connect の「オリジナルをエクスポート」（.zip の中の .fit）、Wahoo、Zwift、Strava の元ファイル | session の sport・sub_sport・start_time・total_distance・total_timer_time | session の sport |
| GPX | Strava・Garmin の GPX 書き出し、多くの記録アプリ | trkpt の時刻と位置から距離と時間を計算（位置はその場で捨てる） | `<type>` があれば使う。無ければ取り込む時に選ぶ |
| TCX | Garmin の古い書き出し、TrainingPeaks | Lap の DistanceMeters・TotalTimeSeconds、Activity の Sport | Activity の Sport |
| .zip | Garmin Connect の書き出し | 中の .fit・.gpx・.tcx を順に読む（ブラウザの DecompressionStream で展開、ライブラリなし） | 上と同じ |

- 画面: メニューの「冒険」→「記録を取り込む」でファイルを選ぶ（複数可）。読んだ記録の一覧（日時・種目・距離・増える冒険の距離）を出して、「取り込む」で確定する。
- FIT の読み取りは、テスト用の `tests/fit-decode.ts` を元に、圧縮した時刻のヘッダ・開発者のフィールド・big endian にも対応した実行時の読み取り（`src/shared/fit-read.ts`）を作る。
- 同じ記録を 2 回数えない: 種目と開始時刻（±2 分）が同じなら同じ記録とみなす（Garmin と Strava から同じ記録を取り込んだ時も）。
- 取り込める期間: 冒険を始めた日の 7 日前より後の記録だけ【初期値】。何年分もの過去の記録で、一度に世界が開いてしまわないように。11 章の 6。
- 速さの検査: 種目ごとの上限（ラン 25km/h、ウォーキング 10km/h、自転車 70km/h【初期値】）を平均の速さが超える記録は、取り込まない（車で移動した記録が混ざった時など）。

### 3.2 種目ごとの倍率【初期値】

| 種目（FIT の sport） | 倍率（実際の 1km → 冒険の km） |
|---|---|
| ラン（1）・トレイルラン | 10 |
| ウォーキング（11）・ハイキング（17） | 6 |
| 自転車（2）屋外 | 2 |
| 自転車 屋内（トレーナー、sub_sport 6・58） | 2（ほかのアプリで漕いだ分） |
| 水泳（5） | 40 |
| そのほか（距離のある種目） | 3 |

- 距離の無い種目（筋トレ・ヨガ）は数えない。時間から換算する案は 11 章の 3。
- 倍率は「ラン 1km = ゲームの自転車 10km」を基準に、運動の大変さがおおよそ揃うように置いた。根拠は粗い。遊んでみて変える。

### 3.3 端末ごとの取り込み口（段階）

| 段階 | 端末 | 口 | 必要な物 |
|---|---|---|---|
| A1 | ウェブ（PC・スマホ） | ファイル | なし |
| A3 | iOS アプリ（P4） | HealthKit のワークアウト（Apple Watch の記録。距離・種目・日時） | Capacitor のプラグイン、ヘルスケアの読み取りの許可。審査の申告（9.4 の健康の区分。端末の外へ出さないので「収集しない」で済む見込み【未確認】） |
| A4 | 全部（P3 の後） | Strava API・Garmin Connect の API | サーバー（OAuth の秘密の鍵を置く）、各社への登録。Garmin は事業者の承認が要る【未確認】。Strava は利用規約で他の人への表示に制限がある【未確認】 |

Apple のヘルスケアの書き出し（export.zip の中の巨大な XML）は、ウェブでは扱わない【初期値】（数百 MB になり、スマホのブラウザで読めない見込み）。Apple Watch の人は A3 まで待つか、記録を FIT・GPX で書き出すアプリを使う。

## 4. 取り込んだ後の旅

### 4.1 アプリを開いている間（A1）

- 取り込んで冒険の距離が増えたら、「旅に出る」で眺める乗り方（未走行の道を優先）に入る。眺める乗り方の設定（視点の自動切替・30fps・HUD を消す）はそのまま。
- 速さは眺める乗り方の出力（今は手動の出力の設定と共通）で決まる。冒険の距離が多い時は 4 倍【初期値】の早送りを選べる（遠くの道路の生成が間に合う範囲で。【未確認】）。

### 4.2 閉じている間も進む（A2）

- 「旅に出る」の後にアプリを閉じても、ライダーは走り続けたことにする。次に開いた時、閉じていた時間 × 25km/h【初期値】（冒険の距離が尽きればそこまで）だけ、まとめて進める。
- まとめて進める計算: 走行の物理を描画なしで回し（`Ride.step`。1 時間で 43 万歩、デスクトップで 1 秒程度の見込み【未確認】）、道路は Worker に順に作らせる。進める間は「旅の続きを計算している（残り 12km）」を出す。
- 旅の記録: 開いた時に、その間の旅を 1 枚にまとめて見せる。走った距離、通った町、立ち寄った喫茶店（スタンプが付く）、見えた名所、最高地点、地図の上の線。文言は事実だけ（CLAUDE.md）。
- 共有（P3）の後は、閉じている間の旅も、ほかの人には眺めているライダーとして見せるかを決める（後で）。

## 5. 画面

- 起動画面の「はじめから」: 自由／冒険を選ぶ。
- 走行中: 冒険の残り（km）を、走行の表示に 1 つ足す（冒険の時だけ）。
- メニューの「冒険」: 残り、取り込んだ記録の一覧（日付・種目・実際の距離・増えた距離）、「記録を取り込む」「旅に出る」。
- 世界地図: 冒険では走っていない所を淡くする（2 章）。

## 6. データ

保存（`SaveData`）に足す。

```ts
adventure: {
  mode: "free" | "adventure";
  /** 冒険を始めた日時（Unix 秒。取り込める期間の基準） */
  since: number;
  /** 残り (m) */
  balance: number;
  /** 使った合計 (m) */
  spent: number;
  /** 取り込んだ記録（合計だけ。位置は持たない） */
  imports: { id: string; sport: string; start: number; distance: number; seconds: number; credit: number; source: "fit" | "gpx" | "tcx" | "healthkit" }[];
  /** 閉じている間の旅（A2） */
  journey: { startedAt: number; lastSimulated: number } | null;
} | null
```

`imports` は 1 件 100 バイトほど。毎日 2 件で 1 年 70KB。古い物は合計にまとめて捨ててよい（後で）。

## 9. 仕様との関係

| 仕様 | 関係 |
|---|---|
| 概要 1 コンセプト「ほぼ無限遠の共有マップ」 | 冒険でも世界は同じ 1 つ。開き方が人ごとに違うだけ |
| 概要 2.1 3 つの乗り方 | 4 つ目の乗り方ではなく、世界の開き方の選択として足す。眺める乗り方を旅に使う |
| 概要 6「経験値・レベル・通貨・装備の販売は置かない」 | 冒険の距離は通貨に近い。買える物は「未走行の道を進むこと」だけにし、品物・課金とはつなげない（11 章の 8） |
| 概要 9.4 健康の区分 | 取り込んだ記録は端末の中だけ。合計だけを持つ |
| 概要 12「課金」は対象外 | 冒険の距離を課金で増やさない |
| トレーナー連携の草案 | トレーナーで走るのは冒険の距離を使わない。トレーナーの記録（B2 の FIT）を取り込み直しても数えない（ゲームの中で走った分なので。sub_sport 58 と製造者 255 で見分ける） |

## 10. 決めずに進めてよい点

- 冒険の距離の表示の単位（km、小数 1 桁）。
- 旅の記録の見た目（A2 で作って見てもらう）。
