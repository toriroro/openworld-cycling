## 確かめていないこと・気づいた点

- **Firefox**: Playwright の Firefox（firefox-1555）がこの PC で起動しない（Windows の side-by-side 構成のエラー。Visual C++ ランタイムが足りない可能性）。SpiderMonkey での一致は未検査。
- Playwright の Firefox と WebKit を取得した時、共有の置き場（`%LOCALAPPDATA%\ms-playwright`）にあった古い版（chromium-1228、chromium_headless_shell-1228、webkit-2104、ffmpeg-1011）を Playwright が自動で削除した。どれも Playwright 1.64 では使わない版。必要なら各プロジェクトで `npx playwright install` を実行すると戻る。
- 平面交差では2本の道路の路面の高さが最大 0.7m ずれている（主要道どうしは互いを見ずに縦断を決めるため）。3D でつなぐ時に接続点の円形の舗装面で吸収するか、M2 で決める。
- 橋が 32km 四方で約 50 か所・8〜9 km（道路の約 2%）。浅い谷を高さ 6m 以上で 40m 以上渡る所が多い。3D で見て多すぎれば、縦断の平滑化（σ 30m）か橋の条件を見直す。
- 海岸線ぎりぎりを通る道は少ない（結節点を結ぶ道が海から 1〜2km 内陸を通る）。
- 地形の陰影と色は 2D 地図での確認用で、3D の見た目は M2 で作る。
