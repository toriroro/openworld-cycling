# M3 走行 — 確認のまとめ

2026-11-13。遊べる URL（ローカル）: http://localhost:5180/ （開発サーバー `.claude/launch.json` の dev）。M2 の自動カメラは http://localhost:5180/?mode=m2 。

計測と画面写真は Windows のデスクトップ（RTX 4060 Ti、Chrome）。**スマホ・タブレットの実機では確かめていない。** 縦横・タッチの確認はデスクトップ Chrome の画面の大きさを変えたもので、実機の性能や操作感は示さない。

## 完了条件（モック仕様 10章）

| 条件 | 結果 | 記録 |
|---|---|---|
| 起点から3つの景観を自分の操作で走れる | 手動の入力元（Space を押し続ける、180W）で、起点 葛郷 → 海岸 28.0km → 平野 61.3km → 山岳 95.9km（獲得標高 1,262m、走行時間 3 時間 54 分）。着いた地点の景観の重みは それぞれ 海岸 1.00・平野 1.00・山岳 1.00。分岐は行き先を指定して経路に沿って自動で選んだ（時間は 30 倍に速めた） | `m3/ride/` |
| 分岐を選べる | 接続点の 150m 手前から候補（矢印・行き先の地名・距離）を出す。← ↑ → と候補のボタンで選べ、選ばなければ直進に近い道。テストで既定でない候補を選んで、その道へ進むことを確かめた | `m3/check/branch.png`、`tests/ride.test.ts` |
| 物理の照合テスト | 抵抗なしの位置エネルギー、8% 下りの終端速度、制動距離2種、登りの釣り合いの速度 5 条件（0〜15%、120〜250W）、停止からの逆走なし。すべて合格 | `tests/physics.test.ts` |
| 4つの画面の大きさで重なりがない | 1440×900・844×390・390×844・1024×768 で、走行情報・メニュー・道路名・分岐・U ターン・タッチの操作ボタンが重ならず、画面からはみ出さない。押す対象はすべて 44px 以上。メニューを開いても画面に収まる | `m3/check/size-*.png`、`results.json` |

テストは 29 件（世界生成 12、ストリーミング 3、物理 10、走行 4）すべて合格。型検査・本番ビルドも通る。

## 作ったもの

- 走行物理（downhill-3D から移植、出力は入力元から受ける形）。手動（押している間 50〜400W の設定値）と自動。未舗装路は転がり抵抗を上げる
- 道路網の上の走行: 左側通行、カーブの手前の自動減速（横加速度 4 m/s²）、分岐、行き止まりの折り返し、停止中の U ターン、左右位置（A / D、タッチの左下）
- 行き先までの最短経路（地図で行き先を指定する画面は M4）
- 視点: 後方・一人称・ドローン（C、メニュー）。地形にめり込まない
- 画面: 左下に走行情報、左上にメニュー（一時停止・視点・眺める・出力・画質・時刻）、上中央に分岐の候補、タッチ端末は右下に漕ぐ・ブレーキ。縦画面は情報を上・操作を下。タブが隠れたら一時停止
- 植生: 木（遠くは十字の板、いちばん近い 3 本は立体）、低木、岩、道路沿いの草の株。密度は景観タイプで変え、道路の近く・水・急斜面には置かない

## 確かめていないこと・残っていること

- 実機（スマホ・タブレット）、Safari、Firefox での動作と性能。タッチ操作は Playwright でタッチありの画面にしただけで、指で触って確かめていない
- 3つの景観を走る確認は、Space を押し続ける操作と分岐の選択を自動で行った。人が操作したのではない
- 地図で行き先を指定する画面、小地図、眺める乗り方の仕上げ（視点の自動切替・HUD を消す・フレームレート上限）は M4
- ライダーと自転車の作り直しとパーツのカスタマイズは別セッションでブランチ `rider-detail` にある（まだ main に入れていない）
