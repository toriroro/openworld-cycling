# M2 3D の地形と道路 — 検査のまとめ

2026-11-13。生成器 `GENERATOR_VERSION = 3`、起点 葛郷（種 6）。

計測は Windows のデスクトップ（GPU: NVIDIA GeForce RTX 4060 Ti、Chrome のヘッドレス、画面 1440×900）。**スマホ・タブレットの実機では確かめていない。** 軽量画質もデスクトップの GPU で動かした値で、実機の性能を示さない。

## 完了条件（モック仕様 10章）

道路に沿って 12.5km 進んで道を記録し、その道を往復（1往復 = 1周）。4周で合計 100km を 200 m/s で加速移動した。各周の終点・起点で止まり、ストリーミングが落ち着いてから gc を2回かけて測った。結果は `m2/drive-2026-11-13T05-42-36-764Z-standard/` と `m2/drive-2026-11-13T05-51-35-513Z-light/`。

GPU の形状の数（three.js の `renderer.info.memory.geometries`）は「一度描いて、まだ捨てていない形状」の数で、それまでに見た向きで変わる。そのため1周目の終点だけ 316 で、2周目から 339 に落ち着いた。ヒープの終点の幅（44.7〜49.6MB）は gc の時機による揺れで、周を重ねても増え続けてはいない。

## 画面写真

`m2/shots/` に景観3種と林道。標準（1440×900）と軽量（844×390）。

- 海岸 `coast-*.png`: 湾の岸の道から海を向いた視点（カメラを海へ向けて固定）
- 平野 `plain-*.png`
- 山岳 `mountain-*.png`（標高 1,140m の山道、谷側のガードレール）
- 林道 `gravel-*.png`（コードで描いた砂利、2本の轍、中央の草の筋）

## M2 で変えたこと・決めたこと

- 生成器 v2・v3（海沿いの結節点、海岸の傾き）。`m1-summary.md` の追記を参照。
- 描く範囲の【初期値】をモック仕様 5.1・5.3 に書き戻した（近景に分ける距離 600m、中景 2,600m、遠景 24km、道路 1.6km。軽量はそれぞれ 380m・1,800m・12km・900m）。
- 未舗装路の路面は外部素材を使わず、砂利の模様をコードで描く（`src/render/gravel-texture.ts`）。

## 確かめていないこと・残っていること
