# 北海道 H0: データの通し試作（2D）— 2026-11-17

[北海道の草案](../../docs/history/specs/2026-11-17-hokkaido-draft.md) 7 章の H0。札幌の中心 20.5 × 20.4km を、取得 → 変換 → 2D 地図まで通した。3D（ゲーム）にはまだ入れていない。

## 動かし方

```bash
npx tsx scripts/hokkaido/build-h0.ts
```

開発サーバーで `map.html?world=hokkaido` を開く。出力 `public/data/hokkaido/h0/` は git に入れない（元データから作り直せる）。数字は `h0-report.json`。

## 作った物

| ファイル | 内容 |
|---|---|
| `scripts/hokkaido/dem.ts`・`png.ts` | 標高タイルの復号（Node の zlib だけ）、5A → 5B → 10B で欠けを埋めて世界座標の 5m 格子に |
| `scripts/hokkaido/osm.ts`・`raster.ts` | OSM の読み込みと投影、多角形の輪の組み立て、水・土地利用の 10m 格子 |
| `scripts/hokkaido/roads.ts` | 走る道の選び方、点の共有での接続点、12m 未満でつながる接続点をまとめる、短い行き止まりを消す、向心キャットマル・ロムで 2m 間隔、縦断（橋・トンネルは両端を直線、σ12m の平滑化、接続点の前後 30m で高さ合わせ） |
| `scripts/hokkaido/dual.ts` | 上り・下りが別の線の道路を 1 本にまとめる（逆向き・同名・40m 以内を相手にし、2 色に塗って片側を残す。交わる道は残す側へ付け替え。高さは両側の車道の位置の平均） |
| `src/shared/world/hokkaido.ts` | 実行時の窓口 `HokkaidoTerrain`・`HokkaidoWorld`（生成の世界と同じ `sample`・`landscape`・`region`。三角関数・DOM なし） |
| `src/workers/world.worker.ts` ほか | `init` に `world: "hokkaido"` を足し、Worker が変換データを読む。2D 地図に出典の表示、トンネルの破線、市街地の色 |

- 上り・下りの道路: 一方通行の幹線・一般道 487km のうち 419km（86%）が対になっていた。まとめた後は 558 本 217km を残し 570 本 212km を消した。交わる道の付け替え 1,073 点、付け替え先が見つからなかった点 11。2 色に塗る時の食い違い 0。まとめた後に残る対は 0.8km。
- 道路と地面の差（橋・トンネルの外）: 中央 0.02m、99% 0.5m、最大 3.6m。
- 喫茶店: OSM に 317 軒、走る道から 60m 以内に 282 軒（名前は「喫茶店（大通西6丁目）」のような一般名）。展望地 7、峠 2（幌見峠・小林峠）。地名 95（区・地区）。
- 水: 川 5.6km²（豊平川の河川敷と水面）、湖・池 0.85km²。土地利用の付いた所は森 25%、市街地 2.5%（OSM に市街地の面が少ない。2D 地図の多くは高さで色を決めている）。
- 変換データ: terrain.bin 16.8MB、roads.bin 16.3MB、world.json 8.8MB（H1 でタイルに分けて圧縮する）。

## 確かめていないこと

- 3D で走ること（H1）。道路の形と地形のずれ、交差点の形、トンネルの見た目はまだ見ていない。
- 道路の位置を航空写真と比べていない（OSM の精度のまま）。
- 勾配 15% を超える道路（入れない版で 26 本）が実際の急坂か、橋の印の無い立体交差などの誤りかは、縦断図を 1 本ずつ見ていない。
- 上り・下りをまとめた所の端（片側だけになる所）の形。
- 一方通行の道（対にならない 56km）は両方向に走れる道として扱っている。
