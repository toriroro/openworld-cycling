# 北海道: 建物（OSM の外形）— 2026-11-17

[北海道の草案](../../../docs/history/specs/2026-11-17-hokkaido-draft.md) 15・16 章。札幌の中心（H0 の範囲）に、OSM の建物の外形から作った建物を出した。

## 動かし方

```bash
npx tsx scripts/hokkaido/extract-buildings.ts
```

```bash
npx tsx scripts/hokkaido/build-h0.ts
```

1 つめは Geofabrik の北海道の抽出（`assets-source/hokkaido/pbf/`）から範囲の建物の外形を取り出す（北海道全体を読んで 9 秒）。2 つめが変換。確認は `node scripts/hokkaido-buildings-shots.mjs`（`QUALITY=light` で軽量画質）。

## したこと

| 所 | 内容 |
|---|---|
| 取得 | Geofabrik `hokkaido-261116.osm.pbf`（190,128,246 バイト、SHA-256 は `assets-source/hokkaido/pbf/manifest.json`）。ユーザーの了承を得て取得 |
| PBF の読み手 | `scripts/hokkaido/pbf.ts`。zlib と自作の protobuf の読み手だけ（ライブラリなし） |
| 変換 | `scripts/hokkaido/buildings.ts`。外形 → 面積を保つように縮めた最小の外接長方形。一番近い道路（住宅街の道を含む）に沿う辺を幅にし、道路の側を正面にする。走る道に重なる建物は捨てる。型・階数は札（9 割以上が `building=yes`）・面積・札幌の中心からの距離・幹線沿いかで決める。階数・高さの札があればそれを使う。家の屋根は無落雪（箱形）55%、三角 25%、片流れ 12%、寄棟 8% |
| 描画 | `src/render/real-buildings.ts`。近く（標準 260m・軽量 160m の区画）は生成の世界と同じ 8 つの型で細部まで、遠く（標準 1.3km・軽量 650m）は壁と屋根の色の付いた箱（三角形 10）。どちらも 1 組のメッシュ（近くは材質の数、遠くは 1 つの描画命令）。区画の組が変わったら、新しい組を 1 フレーム 4ms を目安に少しずつ作って入れ替える。建物の敷地には木を置かない |

- 建物を作る時間（1 フレーム）: 標準で 95% が 12ms 以下、最大 26ms。目安の 4ms を超える。細部の多い大きな建物 1 棟、または材質 1 つ分のメッシュの変換が 4ms を超えるため。
- 自動で 60 秒走った時のフレーム間隔（自動操作のブラウザ、時間 4 倍。実機の値ではない）: 標準で中央 33ms・95% 100ms（建物の前は 95% 67ms）、軽量で中央 50ms・95% 67ms。
- JS のヒープ: 標準 520MB、軽量 274MB（建物の記録 26MB を含む）。
- 生成の世界は変わらない（標準 60万・154、軽量 31万・101）。テスト 106 件・本番ビルドが通る。

## 画面写真

場所ごとに `-chase`（追う視点）、`-above`（上から）、`-far`（遠くから）。`-light` は軽量画質。

## まだの所・確かめていないこと

- 住宅街の道（走らない道）を描いていない。家が地面の上に並んで見える。走らない道を見た目だけの路面として描くのが次の候補。
- 高さはほとんど推定（札があるのは 2.5%）。中心部の大きな建物は高さと形が実物と違う。PLATEAU（札幌の整備範囲は未確認）で高さを入れられる。
- L 字・複雑な形の建物は長方形にしている。1.3km より遠くには建物が無い。
- 1 フレームの作る時間が目安を超える（上）。スマホの実機では確かめていない。
- 店の看板の文字は生成の世界と同じ業種の札（実在の店名は使わない）。

## 追記（同日）: 住宅街の道・敷地・Worker

[草案](../../../docs/history/specs/2026-11-17-hokkaido-draft.md) 17・18 章。上の数字（描画量・フレーム間隔・作る時間）はこの前のもの。今の値は `results.json`・`results-light.json`（同じ名前で上書き）と草案 18 章の表。

- 走らない道（住宅街の道 5,226km・歩道と小道 5,561km。範囲の外へ伸びる分を含む）を見た目だけの路面にし、地形をそれに合わせた。
- 建物ごとに敷地（庭と正面の駐車場）を描き、土地利用の無い市街地の地面を砂利と土の色にした。緑の地面がむき出しの所は減った（`maruyama-above.png`・`toyohira-chase.png`）。
- 建物・敷地・道の形を Worker で作るようにした（メインスレッドは 1 回 0.5ms 以下）。
- 視点の高さを求める光線が交差点の路面の大きなメッシュをなめて 1 フレーム 40ms を超えていたのを直した（札幌の起点で 15fps → 60fps）。
- まだ: 道の交わる所の形（四角い端を重ねているだけ）、縁石・電柱・街路樹、建物の高さの多くは推定、スマホの実機。
