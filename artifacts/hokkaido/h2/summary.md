# 北海道 H2 札幌圏の結果（2026-11-17）

[北海道の草案](../../../docs/history/specs/2026-11-17-hokkaido-draft.md) 20 章のまとめ。範囲は南 42.79・西 140.98・北 43.33・東 141.72（世界座標で 60.0 × 60.0km。石狩の海岸、小樽、江別、北広島、千歳の北、定山渓、中山峠の南）。

## 作り直し方

```
npx tsx scripts/hokkaido/fetch-dem-h2.ts --fetch      # 標高タイル（取得済み。assets-source/hokkaido/h2/dem/）
NODE_OPTIONS=--max-old-space-size=12000 npx tsx scripts/hokkaido/build.ts h2   # 約 1.5 分
npx tsx scripts/hokkaido/build.ts h0                  # 比べる用（実行時は使わない）
```

## 確かめていないこと

- スマホの実機（頁の読み込みの時間・メモリ）。デスクトップの Chrome だけで確かめた。
- 遠くへ走り続けた時のメモリ。地形の頁は視点から 5km より遠い物を捨てるが、建物・走らない道・歩道の頁は捨てない（H2 の全部を読んでも 1 つのスレッドで 75MB ほど【計算】）。

- 本番ビルド（`dist`）には `public/data/hokkaido/` の h0・h2 がそのまま入る（411MB）。配信は H3（R2）で決める。
