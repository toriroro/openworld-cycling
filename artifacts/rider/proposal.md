### 描画量

自分の自転車とライダーだけで、標準 **92 命令・8.3万三角形**（影を含む）、軽量 **47 命令・4.2万三角形**。部品と材質ごとに描画が分かれているのが原因で、軽量の上限 150 命令の 3 割を占める。

## 2. 作り直しの方針（案）

- **描画をまとめる**: ライダーは服・靴・ヘルメットを含めて皮膚つきの形状1つ、自転車は「固定部・ハンドルまわり・前輪・後輪・クランク」の5つ程度にする。色は各頂点が「色の表」（小さなテクスチャ）の何番を使うかで決め、カスタマイズは色の表を書き換えるだけにする。見込み: 標準 92 → 約 16 命令、軽量 47 → 約 7 命令。浮いた分を三角形に回す（標準は1回の描画で約 6 万、軽量は約 2 万の簡略版）。
- **軽量画質の簡略版**: 同じ部品を少ない分割で作った版を持ち、軽量では簡略版を使う（スポークは本数を減らす、細かい部品は省く、ライダーは三角形を減らした版）。
- **自転車**: 駆動系を右側へ。フレームは管の太さと断面を部位ごとに変え、ヘッドチューブ・BB・フォーククラウン・エンドを作る。ディスクブレーキ（またはリムブレーキ）、ブラケットとレバー、ボトルケージ、サドルの形、リムの高さ、タイヤの形、チェーンを板で。
- **ライダー**: 短い髪と眉、ヘルメットを頭に合わせて下げて通気孔を作り直す、サングラスをフレームとレンズに、あごひもを顔に沿わせる、ジャージに襟・ファスナー・切り替え、シューズに靴底・ダイヤル、ソックスの長さ。

## 3. カスタマイズできるパーツ（案）

| 対象 | 選択肢 |
|---|---|
| フレーム形 | エアロ（平たい管）／軽量（細い丸管）／クロモリ（細い丸管・水平のトップチューブ） |
| フレーム色 | 本体の色と差し色（色見本 12 色ほど） |
| ホイール | リムの高さ 浅い／中／深い。リムの色 |
| タイヤ側面 | 黒／飴色 |
| バーテープ・サドル | 色 |
| ジャージ | 柄（無地／胸の帯／肩の切り替え／縦の線）と2色 |
| ビブ | 色 |
| ヘルメット | 形（通常／エアロ）と色 |
| サングラス | レンズの色 |
| シューズ・ソックス | 色、ソックスの長さ |
| 体 | 肌の色、髪の色 |

設定は版番号つきの1つのデータ（例: `{ version: 1, bike: {...}, rider: {...} }`）にして、M4 の `platform` の保存にそのまま載せられる形にする。画面はメニューから開く「自転車と装い」。
